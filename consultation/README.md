# 編成相談

## 目的
土地4〜8／対人戦／特定メタの入口、家門別の全武将選択、テンプレート採用件数による人気順、相方逆引き、編成ごとの戦法・能力振り・兵学・条件を提供する。

## データ
- 武将: assets/database.live.json（404時のみ database.json）。assets/s4-additions.json は空欄の補完用。ライブデータを優先。
- S1〜S3: 既存 formations.live.json（404時のみ formations.json）。
- S4人気順: assets/s4-templates.json の105掲載表のみ。記事本文・FAQ・他サイトの5件を母数へ混ぜない。
- 本館用 formations.json にも105件を追加。season-context.js がS4スナップショットを同じIDでマージするため、古いMySQLエクスポートでも閲覧できる。MySQLへ直接書き込む変更ではない。
- S4原典: https://www.sanguo-zhi.com/entry/s4-template/ （2026-10-01取得）
- 105編成、315武将枠、全て既存武将IDと対応。コスト合計は全編成一致。
- 勇猛無前／三河弓兵／直言極諫／赤備え は出典表記を保持し、未確定の戦法IDを割り当てない。
- 採用件数: 掲載表1件につき各武将1回。同じ三人でも戦法・兵種等が異なる別掲載案は別件。本文の出現回数ではない。
- 同率はふりがな順。0件を除外しない。家門は武将マスターの family に基づく。
- 表示シーズンまでに登場する全武将を対象とする。人気順と編成一覧は選択シーズンの完全一致。mobunagaSeason / mobunaga_season を本館と共有。
- 土地ごとの兵損・勝率・連戦可否は未集計。掲載Tierは出典の評価であり相性判定ではない。
- 元のSites版はレビュー用として保持。本番の正はこのリポジトリ。

## 検証
JavaScriptは同一ソースの構文確認、純粋ロジック・DOMスタブでの操作検証を実施。ブラウザでの実表示、PHP実行、本番サーバーへの反映はこの作業環境では未実施。

既存テンプレートの掲載シーズンを登場時期の根拠として併用する。Tierが初めて付いたシーズンだけで登場時期を決めると、S1掲載済みの星4武将が消えるため。
