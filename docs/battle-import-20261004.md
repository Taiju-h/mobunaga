## 取り込み

本番へこのコミットをデプロイした後、資料館の「敵勢力の解析」→「記録の登録・補完」から、解析済みJSONと元画像ZIPを認証付きでDBへ登録する。生データはGitに含めない。JSONはコードとして実行せずデータとして読む。認証・CSRF保護付きPOSTのみが書き込みを行う。GETでは登録しない。元画像を保存するにはCLIに元ZIPを展開した `frames` ディレクトリを渡す。

```bash
cd /var/www/uzero.style/nobunaga
php bin/import-battles.php --batch=/var/www/.nobunaga-battles/s4-20261004.json --dry-run
php bin/import-battles.php --batch=/var/www/.nobunaga-battles/s4-20261004.json --frames-dir=/absolute/path/to/frames
```

`--frames-dir` 未指定時はテキスト・参照情報のみ投入する。後から画像付きで再実行すると画像だけ補完する。各画像のSHA-256・サイズがマニフェストと一致しなければ全体をロールバックする。スキーマ追加不要。既存の `form_submissions` と `form_submission_files` を使用する。

全バッチ共通のMySQLアドバイザリロックとトランザクションにより、同時実行・再実行で二重登録しない。既存の同日時記録は手動編集したメタデータを維持して補足だけ追加し、削除・スパム判定済みの記録は復活させない。
