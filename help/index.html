HOW TO USE

モブナガの使い方

最初に自分のシーズンを選び、そのシーズンで登場済みの武将・戦法・編成だけを見ます。未来シーズンの情報やコメントを混ぜないのがモブナガの基本ルールです。

1. シーズンを選ぶ

初回アクセス時に「あなたのシーズンは？」が表示されたら、現在遊んでいるS1 / S2 / S3 / S4を選びます。後からヘッダーのシーズン選択で変更できます。

武将・戦法・編成・コメントは選択シーズンを基準に表示されます。

2. 武将・戦法・編成を探す

武将録は能力・特性・Tier、戦法録は効果・発動率・状態異常、編成指南は3武将の組み合わせと推奨戦法を確認する場所です。

検索欄では武将名・戦法名から絞り込めます。詳細画面には共有URLとコメント欄があります。

3. コメントする

武将・戦法・編成の詳細画面から投稿できます。投稿は一度「承認待ち」になり、管理者承認後に公開されます。

コメントにも投稿時のシーズンが記録され、自分より未来のシーズンのコメントは表示しません。

4. 実戦報告を送る

編成詳細の「みんなの実戦報告」から、戦報画像付きで「この編成で勝った」「この編成に勝った」を投稿できます。

勝敗だけでなく、刺さった戦法・苦しかった相手・兵損などを書いておくと資料価値が上がります。

ANALYSIS ARCHIVE

分析班資料館：武将・敵編成情報の登録

資料館は通常の武将録とは別で、実戦で見つけた敵編成・敵プレイヤー・武将の組み合わせを蓄積する場所です。

  1. 「分析班資料館」に入り、合言葉で入館します。
  2. 「＋ 敵情報を投稿」を開きます。
  3. 敵名・プレイヤー名が分かる場合は入力します。
  4. 編成・武将へ、見つけた武将名を「武将A・武将B・武将C」のように入力します。1人だけ判明している場合は1人だけでも構いません。
  5. 本文には戦法、挙動、強かった点、対策候補、何ターン目に何が起きたか等を書きます。
  6. 戦報や編成スクリーンショットがあれば添付します。JPG / PNG / WebP、10MB以下です。
  7. 元Discord・Web記事等の参照先がある場合はURLも残します。

重要：ここへの投稿は「情報受け箱」への登録です。公開武将録の武将マスターそのものを一般ユーザーが直接追加・書き換える機能ではありません。新しい武将を正式な武将録へ追加する場合は、出典確認後に管理側でマスターへ登録します。

資料館内では敵名・武将名で検索できます。「要注意」を付けた敵編成は上位に固定できるため、次に当たりそうな相手や明確なメタ対象へ使ってください。

迷ったら

「この武将はどこで登録する？」「この戦報はどこへ入れる？」のように、目的だけ分かれば大丈夫です。通常の攻略情報は武将・戦法・編成のコメント、敵固有の情報は分析班資料館、戦報画像は編成詳細の実戦報告へ入れるのが基本です。
