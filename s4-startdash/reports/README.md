# 土地戦報検索

既存の土地ページと同じCSS・顔アイコン・カードを使用する。

- `/s4-startdash/reports/?season=4`：土地5〜8横断
- `/s4-startdash/land7/`、`land8/`：初期土地レベルを指定する入口
- `level=5..8`、`allies=<最大3人の武将ID、カンマ区切り>` を引き継げる。
- 武将選択欄は全137名・家門・名前/かな検索・戦報採用件数順。0件も表示する。
- 自軍は全員一致/いずれか、敵は複数のいずれか。土地・敵・自軍・勝敗・自軍全員のLv上限・本文検索はAND結合する。
- 武将選択欄の家門/名前は選択済み武将を消さない。条件を勝手に緩めない。
- 自軍最高Lv、開始−残兵による兵力減少でもソートできる。比較条件はカードに表示する。

`reports.json` が公開用データ。敵・自軍IDはpeopleと照合し、画像は匿名化済み既存アセットのみ。開始・残兵・戦死・負傷は既存ページの転記値。未確認値はnullにし、0を代入しない。戦法は元画像で確認し、検索用の戦法転記は未対応と表示する。

2026-10-02時点では土地5の4件・土地6の11件。添付HTMLの新規79画像は再取得不可のため未転記。土地7/8を含む未登録データを既存15件と混同しない。新規データを入れる際は、画像の名前除去と全画像の目視確認を完了してからJSONとcoverageを更新する。

検証：`node tests/land-report-search.cjs`。ブラウザ検証は `tests/land-report-search-ui.cjs`（Playwright、ローカルHTTP配信）。
